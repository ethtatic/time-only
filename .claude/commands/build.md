description: Implement the next pending task incrementally using TDD. Verify build and tests after each slice.
---

Read and apply the skill at `skills/incremental-implementation/SKILL.md`.

For each pending task from `tasks/todo.md`:
1. Review the acceptance criteria
2. Load relevant existing code, patterns, and type definitions
3. RED: Write a failing test that describes the expected behavior
4. GREEN: Implement the minimal code necessary to pass the test
5. Run the full test suite — verify no regressions
6. Verify the build succeeds
7. Commit with a descriptive message (see `skills/git-workflow-and-versioning/SKILL.md`)
8. Mark the task complete and advance to the next one

If any step encounters an obstacle, apply `skills/debugging-and-error-recovery/SKILL.md`.
