description: Write a structured specification before writing code. Clarify requirements, generate SPEC.md, confirm before building.
---

Read and apply the skill at `skills/spec-driven-development/SKILL.md`.

Clarification phase — ask about:
1. Objective and target users
2. Core features and acceptance criteria
3. Tech stack preferences and constraints
4. Boundaries (what to always do, ask first about, and never do)

Specification generation — produce a SPEC.md covering:
- Objective
- Commands
- Project structure
- Code style
- Testing strategy
- Boundaries

Save the structured spec as `SPEC.md` in the project root.
Confirm with the user before advancing to implementation.
