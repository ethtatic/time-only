## How to use this file

1. Add new ideas to the **Ideas** table — don't overthink priority yet
2. When an idea is worth building, move it to **Queued** and set a priority
3. When work starts: run `/spec`, create `active/<feature-name>/`, move row to **Active**
4. When shipped: archive `active/` folder to `done/`, move row to **Done**
